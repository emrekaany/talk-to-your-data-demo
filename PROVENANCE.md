# Provenance

This public demo is an independent reimplementation of a generic natural-language analytics interaction pattern.

- No source file was copied from the private Talk to Your Data repositories.
- No private prompt, metadata document, schema, SQL example, configuration, log, screenshot or run artefact is included.
- All runtime data is generated by `synthetic.py` with a fixed seed and fictional values.
- The public implementation uses only Python standard-library modules.
- The two commits that predate this demo contained only the Apache-2.0 license and a placeholder README; they contained no private product code or data.

Concepts such as exact-SQL visibility, read-only execution, bounded output and cancellation-aware limits are common software safety patterns. The implementation in this repository was written specifically for the public demo.
